# Loop AI Harness（LoopAI）安装包

这里只放 LAH 的 Windows 安装包，也是 LAH 自动更新的来源。源码不在这个仓库。

## 下载

到 [最新版本](https://github.com/erdan7891/LoopAI-releases/releases/latest) 下载 `LoopAI.Setup.x.y.z.exe`，运行即可：

- 支持 Windows 10 / 11 64 位；
- 按当前用户安装，不需要管理员权限；
- 安装包没有代码签名，Windows 提示「未知发布者」时，点「更多信息 → 仍要运行」。

## 更新

从 1.0.5 起，LAH 会自己检查新版本。有新版时，任务栏右下角会出现「新版本」按钮，点开就能下载，下载完重启即可完成更新。设置、会话和项目都会保留。

更早的版本请手动下载安装一次新版，覆盖安装即可。
